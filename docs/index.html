What Auto Organizer does

Auto Organizer sorts the loose files in a folder you choose into category folders inside that same folder: images, docs, code, archives, audio, video and other.

How to use it

  1. Click Choose Folder… and pick a folder, for example Downloads.
  2. Check the preview. It lists every file that would move and where it would go. Nothing has moved yet.
  3. Click Organize… and confirm. The files move into their category folders.
  4. Changed your mind? Click Undo Last Run to put the files back where they were.

Frequently asked questions

Which files are moved?
Only regular files sitting directly inside the folder you chose. Subfolders and their contents, hidden files (names starting with a dot) and symbolic links are left where they are.

How does it decide the category?
By file extension. For example, .jpg and .png go to images, .pdf and .docx go to docs, and .zip goes to archives. Files with an unknown extension or no extension go to other.

What if a file with the same name already exists?
Nothing is overwritten. The moved file gets a number added, for example report_1.pdf.

How far back can I undo?
Undo Last Run restores the most recent run in that folder. Each new run replaces the previous undo record, so undo a run before organizing the same folder again.

What is the .autoorganizer-last-run.tsv file?
It is the undo record. It lists each file's old and new location, so Undo Last Run can put everything back. It is hidden, stays in the organized folder on your Mac, and is deleted when you use Undo Last Run.

Why can't I choose my Home folder or the whole disk?
For safety, Auto Organizer refuses the top level of your disk and your Home folder. Choose a smaller folder such as Downloads or Desktop.

Does it need the internet or an account?
No. Auto Organizer works entirely on your Mac, needs no account, and does not connect to the internet.
